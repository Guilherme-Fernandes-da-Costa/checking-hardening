Política de Privacidade — Checklist Hardening

Este aplicativo usa a API do Gmail apenas para enviar, a partir da conta do próprio administrador, um e-mail com o checklist preenchido no formulário.

Nenhum dado de usuários do Google é lido, armazenado ou compartilhado com terceiros. Os dados do formulário são usados somente para registrar o checklist e enviar esse e-mail.
